# Multivariate-horizon-dependent-ensemble

This repo contains the code and data used for the analysis in:

Jiaxiang Ji, Feng Ye, Travis Miles, and Ahmed Aziz Ezzat, A Horizon-Dependent Ensemble Method for Probabilistic Forecasting in Offshore Wind Farms. Accepted for publication in INFORMS Journal on Data Science, 2026.

Please use the reference above if you use parts of the code or data

# Related Prior Research
This work builds upon the AIRU-WRF framework for physics-guided offshore wind forecasting developed by Ye et al. [1]. Related research by Walid et al. [2] investigates the economic and reliability benefits of improved offshore wind forecasts for power grid operations.

[1] Ye, F., Brodie, J., Miles, T., and Ezzat, A. A. (2024). "AIRU-WRF: A physics-guided spatio-temporal wind forecasting model and its application to the U.S. Mid Atlantic offshore wind energy areas." Renewable Energy, 223, 119934. https://doi.org/10.1016/j.renene.2023.119934

[2] Walid, K. B., Ye, F., Ji, J., Ezzat, A. A., Miles, T., and Jiang, Y. (2026). "Economic and Reliability Value of Improved Offshore Wind Forecasting in Bulk Power Grid Operation: A Case Study of the New York Power Grid." IEEE Access, 14, 148337–148357. https://doi.org/10.1109/ACCESS.2026.3737067

[3] Aziz Ezzat, A., Ye, F., Ji, J., and Miles, T. (2025). "AIRU-WRF: Spatial-Temporal Wind Datasets and Forecasts for Data-Science-Based Operational Offshore Wind Forecasting in the U.S. East Coast." Zenodo. https://doi.org/10.5281/zenodo.15642047

# Code and Reproducibility

The experiments were implemented using Python 3.11.0 and MATLAB R2023b (Version 23.2.0.2428915). 

After cloning this repository, please refer to Code_MHP/Explanation.text for instructions on using the provided data and code to train the models and generate the results presented in the paper.
