# Multivariate-horizon-dependent-ensemble

This repo contains the code and data used for the analysis in "A Horizon-Dependent Ensemble Method for Probabilistic Forecasting in Offshore Wind Farms". 

The experiments were implemented using Python 3.11.0 and MATLAB R2023b (Version 23.2.0.2428915). To view preliminary results, after cloning this repo, you can follow the explaination.text under Code_MHP folder to use the data and code to train the model and generate the results for the paper.

This is a work in progress, so changes and additional documentations are underway.

This work is part of the RIA Research Group, check other projects by RIA-Research-Group.
