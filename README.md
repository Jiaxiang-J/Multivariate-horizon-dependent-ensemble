# Multivariate-horizon-dependent-ensemble

This repo contains the code and data used for the analysis in "A Multivariate Horizon-Dependent Ensemble for Probabilistic Day-Ahead Forecasting in Offshore Wind Farms". To view preliminary results, after cloning this repo, you can follow the explaination.text to use the data and code to generate the results.

This is a work in progress, so changes and additional documentations are underway.

This work is part of the RIA Research Group, check other projects by RIA-Research-Group.
