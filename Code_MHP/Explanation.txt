For base model training, use the file "AIRU_WRF_R1.lt.m" and "AIRU_WRF_R1.m" for LTM and STM, respectively. Both base model take "data_test_hour.m" as input. Note that, the function "oneRollPredictFore_r1.m" used should also be added to the path.

For multivariate horizon-dependent probabilistic ensemble, use the file "ens_es_train.ipynb", it load the output from the previous step (LTM/STM output), and output the ensemble forecast.

For other results that shown in the paper:

Figure 1: 1a is produced using "ts_for_roll_with_PI.m", 1b is produced using "ts_for_roll_with_PI_R1.m". Note that, the input required by the codes should be added to the path.
Table 1: 'table1.m' produceds the RMSE for each method, and "dm.m" produces the Diebold Mariano test p values for each method. Note that the function used in each script should be added to the path, and slightly change the variable name in the script to reflect result for different methods.
Table 2: 'get_crps.m' generates the CRPS for each method. Note that the function used in each script should be added to the path, and slightly change the variable name in the script to reflect result for different methods.
Figure 2 and 4: 'ts_plot.m' takes the ensemble output as input to generate the probabilistic forecast time series. Note that, this is the same script to generate the NWP vs. Ground truth figure, just load the output from base model, and allY_Test correspond to the ground truth, allY_NWP corresponde to the NWP. The dimension is hour * location * roll.
Figure 5: The scenario of each method are generated through 'performance_check.ipynb'.
Figure 6: The spatial map is generated using 'spatial_figure.m', just change the index for date or hour to reflect a different map. The time series plot at ASOW-6 is generated using 'asow_fig.ipynb'
Table 3: First, transform the wind speed to wind power based on the power curve. Then use 'pce_new.m' to generate the PCE values, note that the values should divide 15 to reflect the number in the paper.
